# Personal Portfolio

A modern and responsive personal developer portfolio built with **HTML, CSS, and Vanilla JavaScript**. The project showcases a clean UI, interactive elements, subtle animations, and responsive layouts across different screen sizes.

## 🌐 Live Demo

**[View Live Website](https://zainabmustafa.vercel.app/)**

## ✨ Features

* Fully responsive design
* Modern and clean UI/UX
* Responsive navigation with mobile menu
* Interactive hero section
* About and skills sections
* Project showcase with custom CSS-based mockups
* Experience and education timeline
* Functional contact form
* Form validation and submission feedback
* Scroll-reveal animations
* Subtle 3D hover and tilt effects
* Smooth micro-interactions
* Reduced-motion accessibility support

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Vanilla JavaScript**
* **Web3Forms**
* **Git & GitHub**
* **Vercel**

## 🎨 UI/UX

The portfolio uses a modern light-themed design with:

* Clean typography
* Soft gradients
* Rounded components
* Subtle shadows
* Smooth transitions
* Interactive hover states
* Lightweight 3D effects
* Responsive layouts

The animations are intentionally subtle to maintain a professional and user-friendly experience.

## 📱 Responsive Design

The website is optimized for:

* Desktop
* Tablet
* Mobile

All major sections, navigation, cards, forms, and interactive elements adapt to different screen sizes.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/zainab-mustafa14/personal-portfolio-website.git
```

Open the project folder and launch `index.html` in your browser.

No framework or build process is required.
